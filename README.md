# Scarface Overseas 🌍

A modern website for **Scarface Overseas**, an import-export business focused on showcasing products, business information, and connecting with potential global clients.

## 🔗 Live Website

**[Visit Scarface Overseas](https://www.scarfaceoverseas.com/)**

## 📌 About the Project

Scarface Overseas is a business website developed to establish an online presence for an import-export company. It provides information about the company, its products, and its business offerings through a clean, modern, and responsive user interface.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and clean user interface
- Product showcase
- Company information and business overview
- Contact section for customer inquiries
- Smooth navigation and user-friendly experience

## 🛠️ Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Responsive Web Design
